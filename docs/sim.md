# 模拟交易（P4）

> 2026-11-26。与券商无关的模拟账户，用本地日线撮合，用于检验组合与策略。实盘相关的一律不做（见 roadmap §3）。

## 模型

- **账户**（`sim_account`）：名称、初始资金、起始日、交易参数。参数创建后不可修改，否则历史成交会失去依据。
- **委托**（`sim_order`）：唯一的事实记录。只新增和更新状态（待成交 → 已成交 / 已拒绝 / 已过期 / 已撤单），不删除。删除账户时才连同委托一起删。
- **持仓与资金**：不单独存表，每次从全部委托按交易日回放得到（`internal/sim`）。每一笔“委托 → 成交 → 持仓”都可以追溯。
- **已有结果的委托不会被改写**：数据源事后修正日线，不改变已经记录的成交价。

## 默认假设（都是账户参数，可在新建账户时修改）

| 项 | 默认 | 说明 |
|---|---|---|
| 成交时点 | 提交日之后的第一个交易日收盘价 | 不复权收盘价；当天下的单最早下一个交易日成交 |
| 撮合截止 | 只用今天之前的日线 | stockdb 当天收盘价是临时值（24:00 校对）。所以 D+1 成交的结果，要到 D+2 才会出现 |
| 滑点 | 5 个基点 | 买入价上浮、卖出价下浮 |
| 佣金 | 万 2.5，最低 5 元 | 买卖都收 |
| 印花税 | 万 5 | 只对股票卖出收取，场内基金不收 |
| 过户费等 | 不计 | |
| 每手股数 | 100 | 买入须为整手；卖出须为整手，或一次卖光全部可卖数量（零股） |
| T+1 | 当日买入成交的数量当日不可卖 | 场内基金同样按 T+1 处理（不区分跨境 T+0 品种） |
| 停牌 | 当天没有日线则顺延 | 提交后超过 5 个交易日仍未成交则过期 |
| 分红送转 | 按除权乘数折算持股数 | 相当于红利再投资，不计红利税；ETF 分红若数据源没有乘数则不体现 |
| 涨跌停、成交量 | 不处理 | 按收盘价全部成交，会高估流动性差的标的的可成交性 |
| 场外基金 | 不支持 | 申赎规则（T+1 确认、费率）不同，以后单独做 |

## 风控（核心强制执行）

委托提交前，核心依次执行 `sim.Checkers` 中的全部检查，任何一个不通过就拒绝提交。插件或配置只能追加检查，不能绕过。一批委托（例如一次调仓）中只要有一笔不通过，整批都不提交。

默认的 `BasicChecker` 检查以下几项：
- 买卖方向和数量是否合法；
- 单笔金额是否超过上限（参数，0 为不限）；
- 可用资金是否足够（已扣除待成交买单）；
- 可卖数量是否足够（已扣除待成交卖单）；
- 是否满足整手规则。

金额按最新收盘价估算。撮合时会按成交价再检查一次资金和可卖数量，不足则拒绝。

## 调仓

调仓只生成预览，确认后才提交：
- **按组合权重**：组合中的场外基金不能用于调仓。
- **按温度计分层仓位**：最新交易日的估值档底仓，加减最近一次信号的仓位（和回测里“估值底仓 + 温度计加减仓”同一口径），全部投到一只代理证券上（例如沪深300 ETF）。

生成规则：先卖后买，按最新收盘价估算，数量取整手，预留 0.5% 现金覆盖费用。账户里还有待成交委托时不能调仓。

## 触发

每日同步任务结束后，自动撮合全部模拟账户。打开账户页面时也会回放一次，并保存新的撮合结果。
