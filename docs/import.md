# 导入外部日线（mt import-bars）

> 给自己写脚本抓取的数据（如场内基金日线）留的落点。导入后数据与其他来源一样存进本地 `stock_bar`，组合分析、行情页直接可用。

## 用法

```bash
mt import-bars [-c config.yaml] [-source 来源名] 文件.csv
```

- `-source`：写进 `stock_bar.source` 的来源名，默认 `import`。建议按抓取渠道命名（如 `myscript`），方便日后排查。
- 同一代码同一天已有数据时**覆盖**；证券清单里没有的代码会自动加入。
- 任何一行不合法就整个文件不导入（最多列出 20 处错误，带行号），不会出现导入一半的情况。
- 导入的是股票时，运行 `mt breadth -local` 重算市场广度；只导入基金不需要。
- 运行时不要同时开着 `mt serve` 的同步任务（两者写同一个库）。

## CSV 格式

UTF-8（可带 BOM），第一行是表头，列名不区分大小写、顺序不限：

| 列 | 必填 | 说明 |
|---|---|---|
| `code` | ✅ | 6 位代码，沪深 A 股或场内基金（15/16/18/50/51/52/56/58 开头） |
| `date` | ✅ | `YYYY-MM-DD` 或 `YYYYMMDD` |
| `close` | ✅ | **不复权**收盘价，必须 > 0 |
| `mult` |  | 当日除权乘数，缺省为 1。定义：除权日**前一日收盘价 ÷ 除权参考价**；没有除权的日子为 1 |

```csv
code,date,close,mult
510300,2026-11-24,4.012,
510300,2026-11-25,4.050,1
159915,20261125,2.199,1
```

- 只放有成交的交易日，停牌日不要写（也不要补 0）。
- 后复权价由系统链式计算：`hfq_t = hfq_{t-1} × close_t × mult_t / close_{t-1}`。

## ⚠ 除权乘数必须提供的情况

`close` 是不复权价，所以凡是让价格“跳一下”的事件都要给 `mult`，否则后复权价会出现断崖，组合收益会算错：

- **ETF 份额拆分 / 折算**（如 1 拆 10）：乘数 = 前收 ÷ 折算后参考价，例如 1 拆 10 时约为 10。
- **基金分红**：乘数 = 前收 ÷（前收 − 每份分红）。腾讯日线里 ETF 分红没有标注，这也是之前用腾讯拉 ETF 会低估收益的原因。
- **股票送转、派息**：乘数 = 前收 ÷ 除权参考价，参考价 =（前收 − 每股派现）÷（1 + 每股送转）。

拿不准的话，可以在数据源同时取一份不复权价和一份后复权价，用 `mult_t = (hfq_t / hfq_{t-1}) × (close_{t-1} / close_t)` 反推，非除权日的结果应当非常接近 1（误差可以四舍五入成 1）。
